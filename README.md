## Working Style

I prefer small, clear scopes: one useful first version, source files included,
simple test data where possible, and notes that make the work easy to review,
run, and extend.

For marketplace work, use the Upwork Project Catalog link. For direct work,
open a GitHub service request first so the scope is clear before payment.
